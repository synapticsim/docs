## What makes a good bug report

Before filing, please check whether the issue has already been reported.
When you do file one, include:

- **Summary** — a short, specific title (avoid "doesn't work").
- **Steps to reproduce** — the exact sequence of actions that trigger it.
- **Expected vs. actual behavior** — what you thought would happen vs. what
  did.
- **Environment** — simulator + version, aircraft version, and OS.
- **Evidence** — a screenshot, video, or `Console.log`/`.txt` log file if
  available.
- **Scope** — whether it's reproducible every time, intermittent, or
  specific to one livery/airport/aircraft state.

<Callout title="One bug per report" type="info">
  Please file a separate report for each distinct issue rather than bundling
  several unrelated problems together — it makes triage much faster.
</Callout>
