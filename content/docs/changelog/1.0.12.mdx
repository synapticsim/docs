### Systems

<ChangelogList>
    <Added>Pressing `Enter` submits hovered MFW input fields</Added>
    <Added>`H:A220_KBD_ENTER_1` and `H:A220_KBD_ENTER_2` submit hovered MFW input fields</Added>

    <Added>ECL `Normal` index can include section headers</Added>

    <Added>ECL conditional and multi-select items can specify follow-on checklists</Added>

    <Fixed>Weird artifacting when displays are not set to full brightness [^1]</Fixed>
    <Fixed>Weird artifacting on the terrain map image when zooming in</Fixed>
    <Fixed>`GS` mode should enable `A/C TRK` mode on the VSD</Fixed>
    <Fixed>Stepping barometer from `STD` should snap to nearest value [^2]</Fixed>
    <Fixed>EICAS N1 should display in cyan when manual thrust mode is enabled</Fixed>

    <Fixed>`RESERVE/CONTINGENCY` and `NUMBER OF PAX` fields on FMS `FPLN FUEL` page should be optional [^3]</Fixed>
    <Fixed>`RESERVE/CONTINGENCY` field on FMS `FPLN FUEL` page should be pre-filled with the FMS default value</Fixed>
    <Fixed>FMS `POS REPORT` page should display current `UTC` and `DATE`</Fixed>
    <Fixed>FMS `POS REPORT` and `FLT LOG` pages should show placeholder rows when empty</Fixed>
    <Fixed>VOR CRS setting should use station declination instead of aircraft declination</Fixed>
    <Fixed>EXT PWR should automatically engage on engine shutdown and disengage on engine start</Fixed>
    <Fixed>Bus isolation modes did not function correctly</Fixed>
    <Fixed>Arming TOGA should not replace the armed mode with the active mode</Fixed>
    <Fixed>ECL should not automatically skip past completed pages</Fixed>
    <Fixed>ECL checklist should not be completable until all active free text is viewed</Fixed>
    <Fixed>ECL free text items should trigger follow-on checklists</Fixed>
</ChangelogList>
