### Systems

<ChangelogList>
    <Added>N1 preview command indicator in autothrottle protection mode</Added>
    <Added>Ability to `INSERT AS WPT` from FMS `FIX` dialog</Added>
    <Added>Ability to insert runways at flight plan airports as fixes [^1]</Added>
    <Added>Ability to insert ILS navaids as fixes</Added>
    <Added>Automatically display non-normal checklists based on CAS messages</Added>
    <Added>Support for timed, limitation, deferred, and follow-on checklist items</Added>
    <Added>Native checklists in both MSFS 2020 and MSFS 2024</Added>
    <Added>Sentry telemetry opt-in dialog</Added>

    <Fixed>General pass over the ISI to make improvements to performance</Fixed>
    <Fixed>Incorrect VHF navaid icon shown in the FMS `FIX INFO` dialog</Fixed>
    <Fixed>`VREF` offset should not be required to set arrival speeds</Fixed>
    <Fixed>`STATUS` synoptic showed incorrect reading for right side brake temperatures</Fixed>
    <Fixed>Out of date magnetic variation database from October 2025</Fixed>
    <Fixed>`VPATH` disarms if the aircraft deviates from the lateral flight plan [^2]</Fixed>
    <Fixed>Direct-to with a course draw in the wrong direction if the aircraft is past the fix</Fixed>
    <Fixed>FMS `VIA/TO` page does not allow scrolling past the last input</Fixed>
    <Fixed>Entering `V` in a transponder input should squawk VFR</Fixed>
    <Fixed>`TERR` overlay should not be available on the DU5 map</Fixed>

    <Removed>`ALONG TRK WPT` option on flight plan legs until a correct implementation is made</Removed>
    <Removed>`CTRLD AIRSPACE` and `SUA` symbol layers until they are made more performant</Removed>
</ChangelogList>
