The Synaptic Toolbox is a small taskbar app that manages external services for the A220. This includes the [terrain map server](/pilots/toolbox/terrain) and will soon include the external EFB. Through the Toolbox, these services can be installed, updated, and monitored.

<LinkButton href="https://github.com/synapticsim/releases/releases/download/index-latest/SynapticToolboxSetup.exe">
  Download the Synaptic Toolbox
</LinkButton>


## File locations

| What | Where |
|---|---|
| Settings | `%APPDATA%\com.synapticsim.toolbox\config.json` |
| Logs | `%LOCALAPPDATA%\com.synapticsim.toolbox\logs\toolbox.log` |

The log is cleared each time the Toolbox starts, so copy it before restarting if you need it. The terrain server writes to the same log.
